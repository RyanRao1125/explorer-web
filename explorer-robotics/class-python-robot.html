About This Class

An advanced robot building class using LEGO Spike Prime. Students tackle creative custom builds, advanced programming, systematic testing, and data analysis. This class prepares students for the World Robot Olympiad.

This class features simple machines, such as pulleys and levers, and incorporates them into Lego Robotics. Using these, the students will learn to construct models in order to fufill tasks given by the coach. They will be encouraged to try to explain how their machine works, along with their fellow classmates. They will make fair tests and analyzations about their robots, and will be able to establish problem solving skills, finding the links between cause and effect.

What Students Will Learn

  • Advanced robot building with Spike Prime
  • Creative custom robot design
  • Advanced programming techniques
  • Systematic testing and data analysis
  • Autonomous navigation challenges
  • WRO competition preparation
  • Teamwork under competition conditions
