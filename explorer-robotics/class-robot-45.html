About This Class

The perfect first step into robotics. Students build and code real robots using Spike Essential in a fun, hands-on environment. No prior experience is needed.

At the very beginning, students will be introduced to the EV3 Education set and software. During these classes, the basics of Lego Robotics will be taught in a fun, hands-on experience. The curriculum teaches beginner robot builds and fundamental programming movements. These include simple maneuvers such as forward driving and arched turns. Basic sensor functions will also be taught. Flow controls such as looping and switching will accompany these movements. Of course, these classes wouldn't be much fun without a challenge — so at the end of each session, there will always be a problem for the Explorers to demonstrate their learning and knowledge about the EV3 software.

What Students Will Learn

  • Introduction to the LEGO Spike Essential set and software
  • Basic robot construction and assembly techniques
  • Scratch-based visual programming fundamentals
  • Simple movements: forward driving, turns, and stops
  • Basic sensor functions and how to use them
  • Flow controls: loops and switches
  • Teamwork, problem-solving, and engineering thinking
  • End-of-session challenges to apply what they've learned
