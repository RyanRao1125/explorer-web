About This Class

Students build robots using LEGO Spike Prime and learn Scratch-based programming. This class develops core engineering design skills and prepares students for the WRO Robot Competition.

This class dives deeper into Lego Robotics. During these classes, the Extension set will be introduced. This pack includes many new pieces and recipes for robot design. The student will also learn the basics of EV3/Spike Prime technics. Gear systems and motion transformation will be introduced, as well as many unique machines that make use of these techniques. The students will learn additional programming methods, such as data-logging, porportinal control and sensor calibration. Using these, students will be able to create interesting programs and robot designs.
