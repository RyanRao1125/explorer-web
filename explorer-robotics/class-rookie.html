About This Class

The perfect first step into robotics. In Robot Rookie, young Explorers get hands on with LEGO Spike Essential, building simple robots and learning to bring them to life with block based coding.

Each class blends a short building challenge with a coding lesson. Students learn to make their robot move, turn, and react using motors and simple sensors. Lessons build week to week, from basic driving to short programmed routines, all through play based challenges designed for younger builders.

What Students Will Learn

  • Introduction to the LEGO Spike Essential set and software
  • Basic robot construction and assembly techniques
  • Block based coding fundamentals
  • Simple movements: forward driving, turns, and stops
  • Using motors and simple sensors to make a robot react
  • Teamwork, problem-solving, and engineering thinking
  • Short building and coding challenges
